# AGENTS.md

This file provides instructions for Claude Code, Github Copilot, Codex (and other AI assistants) working with this repository.

The goal is to create a dotnet 10 command line tool which can read a folder of mp4 files.
On the top right, there is a clock which always changes. This must be ignored.
I am interested in videos with movement. If there is no movement in the video except the clock, the video is deleted. There is a dry run where the video is not deleted but at the end an console output is generated with videos with movement and videos without movement.

In the folder test, there are some test videos.
